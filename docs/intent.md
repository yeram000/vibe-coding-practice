# 산업안전교육 웹서비스 — 기획의도

## 문제

| 항목 | 내용 |
|------|------|
| **누가** | 한국의 중소·대기업 (50% 이상 외국인 근로자 고용) |
| **뭐가** | 한국어 부족으로 인한 산업재해 발생 |
| **왜** | 기존 교육 서비스는 형식적(껍데기만, 내용 부실, 한국어 전문가 부재) |
| **구체적** | - 이해하지 못해도 고개를 끄덕임 (불이익 받을까봐)<br/>- 보호구 미착용 (문화차이)<br/>- 현장 은어/한자어/법정용어 이해 불가 |


## 원하는 결과

| 항목 | 내용 |
|------|------|
| **기업 입장** | 외국인 근로자 교육 관리 + 법적 증빙(수료증) |
| **근로자 입장** | 모국어로 배우고 한국어 산업안전 용어 이해 |
| **최종 목표** | 산업재해 감소 + 법정 의무 충족 |


## 대상

| 구분 | 세부사항 |
|------|---------|
| **기업** | 500인 이상 (또는 1,200억원 이상 건설사) 제조/건설업 |
| **기업 담당자** | 안전담당자, HR 담당자 (의사결정) |
| **근로자** | 베트남(1순위) > 우즈베키스탄(2순위) > 미얀마(3순위) |
| **근로자 특성** | 일상 한국어는 가능하나 산업용어 이해 부족 |


## 제약

| 항목 | 내용 |
|------|------|
| **법적** | 산업안전법 준수 (기초교육 4-8시간, 수료증 발급 필수) |
| **기술** | 다국어 지원 (베트남/우즈베키스탄/미얀마) |
| **콘텐츠** | 한국어교육 중점 (용어, 은어, 한자어 설명) |
| **신뢰성** | 형식적 교육 벗어남 (실제 이해도 향상) |
| **장기** | 지정 교육기관 인증 준비 (콘텐츠 자산화) |


## 성공 신호

| 기업 입장 | 근로자 입장 | 최종 신호 |
|----------|-----------|----------|
| ✅ 수료증 발급 | ✅ 이해도 향상 | 📉 산업재해 감소 |
| ✅ 법적 증빙 | ✅ 안전수칙 준수 | 📝 법정 의무 충족 |
| ✅ 관리 효율화 | ✅ 자신감 상승 | 🏆 지정기관 인증 |


## 열린 질문 (위험한 순서)

### 🔴 Q1: 콘텐츠의 법적 효력 (가장 중요)
- **질문**: 우리 콘텐츠 + 수료증이 법적으로 인정받을 것인가?
- **현 상태**: 모름 (지정 기관 아님)
- **영향**: 기업들이 우리 서비스를 선택할 이유가 없을 수 있음
- **해결책**: KOSHA/산업부와 조기 협력 또는 지정기관 인증 준비

### 🟠 Q2: 콘텐츠 팀의 능력 검증 (높음)
- **질문**: 산업안전 전문가 + 베트남어 번역가가 정말 "좋은 수준"인가?
- **현 상태**: "이미 있다"고만 함 (자세한 자격/경험 모름)
- **영향**: 콘텐츠 품질 → 교육 효과 → 기업 만족도 직결
- **해결책**: 초판 콘텐츠 작성 후 사용자 테스트 필수

### 🟡 Q3: 기업의 구매 동기 (중간)
- **질문**: 기업들이 실제로 이 서비스를 유료로 쓸 것인가?
- **현 상태**: 모름 (시장 조사 미실시)
- **영향**: 비즈니스 모델 검증 필요 (구독료 가격대, 계약기간 등)
- **해결책**: 초기 5개사 베타 고객에게 직접 피드백 받기


## 개발 전략

| 단계 | 기간 | 초점 | 산출물 |
|------|------|------|--------|
| **Phase 1** | 2개월 | 웹 플랫폼 + 베트남어 콘텐츠 (기초) | MVP 런칭 |
| **Phase 2** | 3개월 | 콘텐츠 고도화 + 우즈베키스탄/미얀마 추가 | 3국어 플랫폼 |
| **Phase 3** | 2개월+ | 지정 기관 인증 준비 (콘텐츠 자산화) | 공식 인증 신청 |
