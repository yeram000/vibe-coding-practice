# 산업안전교육 웹서비스 — 기술 명세

## MVP 범위 (첫 번째 버전)

**교육 콘텐츠 제공 기반 플랫폼 (베트남어 중심)**

- 기업(안전담당자): 근로자 관리, 교육 배정, 진도 추적, 수료증 발급
- 외국인 근로자: 교육 수강, 진도 저장, 수료 증명

이후 단계: 우즈베키스탄어, 미얀마어 확대 → 지정 교육기관 인증


## 이번 초안에서 만들 것 / 만들지 않을 것

이 문서 아래쪽의 화면·기능 설계는 **최종 목표**다.
이번 초안은 그중 아래 표시된 것까지만 만든다.

### ✅ 만든 화면 (초안 완료)

| 경로 | 화면 | 핵심 |
|------|------|------|
| `/` | 홈 | 맨 위에 한 줄 — **"말이 통해야 안전이 통합니다"** |
| `/login` | 로그인 | 역할(기업/근로자) 전환 |
| `/signup/company` `/signup/worker` | 회원가입 | 기업용·근로자용 입력 양식 |
| `/dashboard/admin` | 기업 대시보드 | 요약 4개 + 최근 수료자 |
| `/dashboard/admin/workers` | 근로자 목록 | 10명, 이름 검색 + 국적·상태 거르기 |
| `/dashboard/admin/workers/[id]` | 근로자 상세 | 인적사항, 누적 이수시간, 교육 이력 |
| `/dashboard/admin/assign` | 교육 배정 | 근로자 여러 명 선택 + 과정·기한 지정 |
| `/dashboard/learner` | 내 교육 목록 | 배정된 교육과 진행률 |
| `/dashboard/learner/course/[id]` | 학습 화면 | 단원 목록 + 어려운 말 사전 |
| `/certificate/[id]` | 수료증 | 이름·과정·이수시간·발급번호, 인쇄 |

### ⏸ 나중에

엑셀 일괄 업로드 · 2단계 인증 · 알림 · CSV/보고서 내보내기 ·
최종 평가 문제은행 · 재시험 횟수 제한 · 부정행위 방지 ·
수료증 디지털 서명 · 공시제 제출용 보고서 자동 생성

### ❌ 이번 초안에서 만들지 않음

| 항목 | 이번에 대신 하는 것 |
|------|--------------------|
| 진짜 로그인·회원가입 처리 | 화면은 있으나 아무 값이나 통과하고, 가입 내용은 저장되지 않음 |
| Supabase 연결 | 코드 안 예시 데이터 파일 1개 (`lib/sample-data.ts`) |
| 교육 영상 재생·음성 더빙 | 영상이 들어갈 자리만 표시 |
| 우즈베키스탄어·미얀마어 화면 | 한국어 화면 + 베트남어 표기 |
| PDF 생성 라이브러리 | 브라우저 인쇄 기능 (새 라이브러리 추가 없음) |


## 화면에서 확인하는 방법 (이번 초안의 완료 조건)

`npm run dev` 로 띄운 뒤 아래 8가지가 모두 되면 이번 초안은 끝난 것으로 본다.

1. `/` 맨 위에 **"말이 통해야 안전이 통합니다"** 가 크게 보인다
2. 홈 → 기업 담당자 → 로그인 → 대시보드까지 **클릭만으로** 도달한다
3. 근로자 목록에 **10명**이 보이고 국적·부서·상태가 서로 다르다
4. 이름을 검색하거나 국적·상태로 거르면 목록이 그에 맞게 줄어든다
5. 홈 → 외국인 근로자 → 학습 목록 → 교육을 누르면 **섹션 목록과 용어 설명**이 보인다
6. 수료한 사람의 수료증을 열면 **이름·과정·이수시간·발급번호**가 보이고, 인쇄 미리보기가 깨지지 않는다
7. 폰 크기(가로 375px)에서 **가로 스크롤 없이** 보인다
8. `npm run build` 가 오류 없이 끝난다


## 사용자 및 사용 흐름

### 1. 기업 안전담당자 (관리자)

```
기업 회원가입 
  → 로그인 
  → 근로자 추가/관리 (외국인 근로자 정보 등록)
  → 교육 배정 (개별 또는 일괄)
  → 진행상황 대시보드 보기
  → 수료자 현황 확인
  → 수료증 다운로드/인쇄
  → 교육 이력 조회
```

**주요 기능:**
- 회사 정보 등록 (회사명, 규모, 산업 분류)
- 외국인 근로자 정보 입력 (이름, 모국, 고용 형태, 배치 부서)
- 개인/팀/전사 단위 교육 배정
- 실시간 진행률 추적
- 수료 현황 조회
- 수료증 일괄 다운로드
- 교육 기록 저장 (법적 증거)


### 2. 외국인 근로자 (학습자)

```
개인 회원가입 또는 관리자 등록
  → 로그인 (베트남어 인터페이스)
  → 배정된 교육 확인
  → 교육 수강 (영상/인터랙티브)
  → 진도 자동 저장
  → 중간 테스트 (이해도 확인)
  → 최종 평가
  → 수료증 다운로드
```

**주요 기능:**
- 모국어(베트남어) + 한국어 병행 인터페이스
- 영상 기반 교육 (한국어 + 베트남어 자막/음성)
- 진도 자동 저장 (중단했다가 다시 시작 가능)
- 현장 용어 설명 (한자어, 은어 포함)
- 간단한 중간 확인 문제
- 수료 시 인증서 받기


## 화면 및 기능 설계

### 기업 담당자 대시보드

1. **로그인/회원가입**
   - 회사 이메일로 가입
   - 2단계 인증 (선택사항)

2. **메인 대시보드**
   - 요약 정보
     * 전체 근로자 수
     * 교육 진행 중: N명
     * 수료: M명
     * 미이수: K명
   - 최근 수료자 목록
   - 종합 진행률 그래프

3. **근로자 관리**
   - 근로자 목록 (이름, 모국, 채용일, 현황)
   - 개별 추가
   - Excel 일괄 업로드
   - 근로자 상세 정보 (채용 형태: 정규/일용, 부서, 연락처)
   - 교육 이력 조회

4. **교육 배정**
   - 배정 방식 선택
     * 개별 배정: 근로자 1명 선택 후 교육 배정
     * 일괄 배정: 미이수자 전체, 특정 부서, 특정 국가 대상
     * 반복 배정: 정기 교육(6개월마다)
   - 배정 날짜 설정
   - 완료 기한 설정
   - 알림 설정 (배정, 미이수 상기)

5. **진행상황 추적**
   - 실시간 진행률 (미시작 → 진행 중 → 완료)
   - 근로자별 진행 상태 표
   - 교육 시작/완료 시간 기록
   - 부서별, 국가별 집계

6. **수료증 관리**
   - 개별 수료증 다운로드 (PDF)
   - 일괄 다운로드
   - 인쇄 준비 (여러 장)
   - 수료증 재발급 (분실 시)
   - 수료 기록 영구 보존

7. **보고서 및 내보내기**
   - 기간별 교육 통계
   - 근로자별 이수 현황
   - CSV/Excel 내보내기
   - 공시제 제출용 보고서 (자동 생성)


### 외국인 근로자 학습 플랫폼

1. **로그인**
   - 간단한 인터페이스
   - 베트남어 기본 설정
   - 개인 번호/이메일로 로그인
   - 비밀번호 찾기 지원

2. **대시보드 (학습자 홈)**
   - 배정된 교육 목록
   - 각 교육 상태 표시 (미시작 / 진행 중 / 완료)
   - 진도 표시 (%)
   - 예상 소요 시간 표시

3. **교육 수강 화면**
   - 섹션별 구성 (5-6개 섹션, 각 20-30분)
     * 1. 산업안전법 기초 (30분)
     * 2. 산업재해 유형과 원인 (30분)
     * 3. 현장 안전수칙 (30분)
     * 4. 보호장비 착용법 (20분)
     * 5. 비상 상황 대응 (20분)
   - 영상 재생 (자막 선택: 베트남어/한국어/이중자막)
   - 음성 선택 (한국어/베트남어)
   - 진도 표시 (현재 위치, 전체 진행률)
   - 일시정지/다시보기 가능
   - 섹션 완료 후 다음 섹션 오픈

4. **학습 보조 기능**
   - "어려운 용어 설명" 팝업
     * 한자어: "위험요인" → "작업 중 발생할 수 있는 위험"
     * 은어/현장용어: "고소작업" → "높은 곳에서의 작업"
     * 법정용어: "안전보건관리체계" → "기업이 안전을 지키기 위해 만든 규칙과 절차"
   - 용어사전 (별도 탭)
   - 자주 묻는 질문 (FAQ)

5. **중간 확인 문제**
   - 각 섹션 후 3-5개 문제 (객관식)
   - 70% 이상 정답 시 다음 섹션 진행
   - 부족 시 해당 섹션 재시청 권장
   - 무제한 재시도 가능

6. **최종 평가**
   - 10개 문제 (전체 내용 총정리)
   - 80% 이상 정답 시 수료 인정
   - 부족 시 재시험 가능 (3회까지)
   - 부정행위 방지 (문제 순서 무작위)

7. **수료증 화면**
   - 수료증 디자인 (보기, 다운로드, 인쇄)
   - 발급 날짜, 교육 기간, 이수시간 기재
   - 고유 인증번호 (기업에서 조회 가능)
   - 디지털 서명 (진정성 증명)

8. **학습 기록**
   - 개인 학습 현황
   - 수강한 교육 리스트
   - 이수 현황
   - 수료증 저장소

## 우려 사항 및 해결 방안

### 1. 법적 요구사항 충족
**우려**: 수료증의 법적 효력 — 공식 교육기관이 아니면 인정되지 않을 수 있음
**해결**:
- 초기 단계: "보조 교육 자료" 성격으로 시작
- 기업들이 이미 지정 기관에서 받은 교육을 관리/추적하는 플랫폼으로 포지셔닝
- 점진적으로 지정 교육기관 인증 추진 (별도 프로젝트)

### 2. 콘텐츠 품질 및 정확성
**우려**: 산업안전법 준수, 법정 요구 내용 누락 위험
**해결**:
- 산업안전보건공단(KOSHA) 기준 자료 기반 제작
- 법무 검토 체크 (산업안전 전문가 자문)
- 버전 관리 (법령 개정 시 즉시 반영)

### 3. 다국어 번역 품질
**우려**: 베트남어 번역의 정확성 — 산업 용어 오역 위험
**해결**:
- 베트남어 전문가 + 산업안전 전문가 함께 검토
- 모국어 사용자 테스트 (실제 외국인 근로자 피드백)
- 반복 개선 루프

### 4. 외국인 근로자의 접근성
**우려**: 
- 모바일 의존도 높음 (회사 PC 없음)
- 인터넷 접근 제약
- 한국어/모국어 혼재로 인한 혼동
**해결**:
- 모바일 최적화 (반응형 디자인)
- 오프라인 학습 자료 제공 (PDF, 인쇄 가능)
- 직관적 UI (텍스트 최소화, 아이콘/시각화)
- 기업에서 근무 시간에 일괄 학습 환경 제공

### 5. 보안 및 개인정보
**우려**: 
- 근로자 정보 유출 위험
- 수료증 위조 방지
**해결**:
- HTTPS, 데이터 암호화
- 접근 권한 관리 (기업 담당자만 근로자 정보 조회)
- 수료증에 고유 인증번호 + 디지털 서명
- 정보주체 요청 시 즉시 삭제 (GDPR 유사 대응)

- [ ] 기업 관리자 대시보드 MVP 완성
- [ ] 외국인 근로자 학습 플랫폼 MVP 완성
- [ ] 베타 테스트: 5개사 이상, 100명 이상의 외국인 근로자 수강
- [ ] 수료율: 80% 이상
- [ ] 기업 피드백: "도움이 된다" 3/5 이상

- [ ] 누적 수료자: 500명 이상
- [ ] 산업재해 감소율 추적 (기업 피드백)
- [ ] 공시제 제출용 리포트 자동 생성 기능 추가

#### 장기 단계 (12개월+)
- [ ] 지정 교육기관 인증 신청
- [ ] 수료증의 법적 효력 인정
- [ ] 다국어 확대 (필요시)
- [ ] TBM(Tool Box Meeting) 일일 점검 기능 추가
- [ ] 다국어 번역 시스템 고도화

### 사업 지표 확인 방법 (출시 이후 — 코드 완료 조건 아님)

> 개발이 끝났는지 판정하는 기준은 위쪽 **"화면에서 확인하는 방법"** 을 쓴다.
> 아래는 서비스를 실제로 운영한 뒤에 보는 숫자다.

1. **교육 효과**
   - 사용자 설문: "교육이 도움이 되었나?"
   - 이해도 테스트: 최종 평가 점수 추적
   - 재수강율: 낮을수록 좋음 (80% 이상 합격)

2. **비즈니스 효과**
   - 기업 확대율 (월별)
   - 수료자 수 (월별)
   - 기업 재계약율 (갱신 시)
   - NPS (Net Promoter Score) 조사

3. **법적 효과** (관계사 피드백)
   - "공시제 제출 시 기록이 도움이 되었나?"
   - "외국인 근로자 산업재해 감소를 느낀다"는 피드백
   - 기업의 교육 기록 제출 용이도


## 다음 단계

1. **콘텐츠 제작**
   - 산업안전 전문가와 협력하여 기초안전보건교육 강의안 작성
   - 한국어 → 베트남어 전문 번역
   - 영상 촬영 및 자막/음성 더빙

2. **기술 구현 우선순위**
   - Phase 1: 기업 담당자 대시보드 (회원가입, 근로자 관리, 교육 배정)
   - Phase 2: 외국인 근로자 학습 플랫폼 (영상 재생, 진도 저장)
   - Phase 3: 수료증 자동 생성/발급
   - Phase 4: 보고서 및 분석 대시보드

3. **베타 테스트**
   - 협력사 5개사 모집
   - 실제 외국인 근로자 50-100명 참여
   - 피드백 수집 및 개선
